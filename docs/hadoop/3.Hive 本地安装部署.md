### 微课PPT大纲：Hive本地安装部署（实操）

---

#### PPT 1：**Hive安装部署 - 引言**
- **内容**：
  - 介绍Hive的作用及其在大数据生态系统中的位置。
  - 说明本次实操目标：在本地部署Apache Hive，完成环境配置。
  - Hive本地部署的整体流程概述：下载Hive、解压安装、配置环境变量、连接MySQL元数据库。

---

#### PPT 2：**Hive安装前的准备**
- **内容**：
  
  - **准备工作**：
    1. **确认依赖**：确保已安装Hadoop和MySQL（与之前内容衔接）。
    2. **下载Hive安装包**：
       - 官方地址：[Apache Hive下载页面](https://hive.apache.org)
       - 示例命令：
         ```bash
         wget https://archive.apache.org/dist/hive/hive-3.1.3/apache-hive-3.1.3-bin.tar.gz
         ```
  - **选择安装路径**：
    
    - 推荐路径：`/usr/local/hive`

---

#### PPT 3：**Hive安装步骤**
- **内容**：
  
  - **步骤1：解压安装包**：
    - 解压下载的Hive安装包：
      ```bash
      tar -xzvf apache-hive-3.1.3-bin.tar.gz
      mv apache-hive-3.1.3-bin/* /usr/local/hive
      ```
  
  - **步骤2：配置环境变量**：
    - 编辑`~/.bashrc`文件，添加Hive环境变量：
      ```bash
      export HIVE_HOME=/usr/local/hive
      export PATH=$HIVE_HOME/bin:$PATH
      ```
    - 更新环境变量：
      ```bash
      source ~/.bashrc
      ```
  
  - **步骤3：检查Hive版本**：
    - 验证Hive安装是否成功：
      ```bash
      hive --version
      ```

---

#### PPT 4：**配置Hive元数据库**
- **内容**：
  - **步骤1：设置MySQL JDBC驱动**：
    - 下载MySQL JDBC驱动，并将其复制到Hive的`lib`目录中：
      ```bash
      wget https://dev.mysql.com/get/Downloads/Connector-J/mysql-connector-j-8.0.32.tar.gz
      tar -zxvf mysql-connector-j-8.0.32.tar.gz
      cp mysql-connector-j-8.0.32/mysql-connector-j-8.0.32.jar /usr/local/hive/lib/
      ```

  - **步骤2：配置`hive-site.xml`**：
    - 复制Hive默认配置模板并进行编辑：
      ```bash
      cp $HIVE_HOME/conf/hive-default.xml.template $HIVE_HOME/conf/hive-site.xml
      vi $HIVE_HOME/conf/hive-site.xml
      ```
      
    - 添加以下配置：
      
      ```xml
      <?xml version="1.0" encoding="UTF-8" standalone="no"?>
      <?xml-stylesheet type="text/xsl" href="configuration.xsl"?>
      <configuration>
      <property>
        <name>javax.jdo.option.ConnectionURL</name>
        <value>jdbc:mysql://192.168.3.100:3306/hive_metastore?createDatabaseIfNotExist=true</value>
        <description>JDBC URL for Hive Metastore</description>
      </property>
      <property>
        <name>javax.jdo.option.ConnectionDriverName</name>
        <value>com.mysql.cj.jdbc.Driver</value>
      </property>
      <property>
        <name>javax.jdo.option.ConnectionUserName</name>
        <value>hive</value>
      </property>
      <property>
        <name>javax.jdo.option.ConnectionPassword</name>
        <value>Hive_password1!</value>
      </property>
      </configuration>
      ```

#### PPT 5：**初始化Hive Metastore**
- **内容**：
  - **步骤1：初始化元数据库**：
    - 使用以下命令初始化Hive元数据库：
      ```bash
      schematool -initSchema -dbType mysql
      ```
    - 确保命令运行无错误，并生成相关表。
    - 然后启动hadoop
    
  - **步骤2：启动Hive CLI**：
    - 使用Hive CLI工具验证配置是否成功：
      ```bash
      hive
      ```
    - 如果成功进入CLI界面，表示安装配置完成。

#### PPT 7：**常见问题与解决方案**
- **内容**：
  - Hive CLI启动报错：检查Hadoop配置和环境变量。
  - JDBC驱动缺失：确保正确下载并放置于`/usr/local/hive/lib/`目录。
  - 元数据库连接失败：检查`hive-site.xml`配置及MySQL服务状态。
